Pro tools for Android power users

The Pro roadmap extends the Android edition with integrated low-level tools while keeping the familiar Commander workflow.

0x

Hex editor

Inspect and edit files at byte level with offsets, hexadecimal values and text representation in one focused view.

>_

Console

Open an integrated command console for advanced file-system and administration workflows without leaving Beyond Commander.

✦

Virus scan

Run on-demand file and folder malware checks from the Android file-management workflow, with clear scan status and results.

⇄

Advanced operations

Extended batch, queue and power-user operations designed for larger or more complex file-management jobs.

S

Sentinel Endpoint

Planned integration with Sentinel Endpoint for device-security status, protection telemetry and security-oriented actions.

Built on Beyond Commander Android

Pro is a planned extension of the Android edition. The standard Android experience remains the foundation; Pro adds the advanced tools above as they become ready.
